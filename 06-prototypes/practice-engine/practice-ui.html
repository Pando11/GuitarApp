    Drill Menu — all 11 §5.2 practice drills

    Every drill below is runnable. The 3 headline drills (Chord-Perfect, Air Changes, One-Minute Changes) plus Weak-Pair Review share the engine in 06-prototypes/practice-engine/; the 8 new modules live in drills/*.mjs and each is wired via a <script type="module"> block below.

    Chord-Perfect (accuracy)

    Place the chord slowly, pick each string, fix any buzz/mute. Accuracy over speed.

    Air Changes (retrieval)

    Lift off the neck, shape the next chord in the air, land all fingers at once.

    Tempo-Scaled Section Loop

    Loop the hard bar at a fraction of tempo, then speed up. Slide 25–125% and re-run the change for 60s (simulated).
    100%

    Wait-To-Play

    Constrained-listener discipline: do NOT strum until the listener is confident it hears the TARGET chord (easyC here).

    Anchor / Pivot

    Find the shared finger that stays put through the change so you pivot instead of lifting everything.

    Spider warm-up

    Walk the fingers up/down the fretboard one string at a time (the classic dexterity exercise).

    Metronome ladder

    Raise the BPM only when the previous level was CLEAN (≥45 changes/min). Climb Em↔easyC from 60 to 140.

    Muted / percussive strum

    Rhythm hand alone — no fretting, no pitch. Score tempo steadiness (on-beat vs off-beat muted hits).

    Count-out-loud

    Lock tempo by counting the 1-&-2-& grid out loud before you strum. Score on-tempo counts.

    Each teaching lesson in 05-content/guitar-lesson-*.json has a matching practice lesson in 05-content/practice/guitar-practice-*.json that drills the same chord set (cumulative).
