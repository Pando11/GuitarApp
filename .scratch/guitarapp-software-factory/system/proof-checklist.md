# GuitarApp proof checklist

Use this before calling a task done.

## Required on every student-facing task

### 1. Gate output
- Run the real gate or check.
- Save the exact command.
- Save the pass/fail output.

### 2. Visible walkthrough proof
- Show the actual screen, flow, or artifact.
- If the change is visual, capture before/after when useful.
- If the change is audio or spoken copy, capture transcript or audio proof.

### 3. Reopen/save proof
- Close and reopen the app or relevant screen.
- Prove the saved state, progress, or memory is still there.

## Verifier pass
- A separate verifier reviews the builder result.
- The verifier checks scope, rules, and proof quality.
- If proof is weak, the task moves back out of Done.

## Never accept
- "The agent said it works"
- one screenshot without flow proof
- green prose without real output
- a save claim without reopen proof
