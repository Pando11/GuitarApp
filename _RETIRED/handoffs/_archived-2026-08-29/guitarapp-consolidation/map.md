- **[ADR-0001 — Always-On Encrypted Sync](docs/adr/0001-always-on-encrypted-sync.md):** RATIFIED (Grill #1, 2026-08-23, owner re-confirmed on this machine). Memory MUST follow student across devices (phone→desktop→memory present). Sync is ALWAYS ON — no opt-in/off toggle (toggle dumps privacy/UX choice onto non-technical users). Privacy by device-side encryption, NOT locality: app encrypts on-device, PocketBase stores ONLY ciphertext it can't decrypt, only student's devices hold key. What is where: on-device (plaintext) = per-chord label, confidence, practice events, per-pair fluency, key; PocketBase (ciphertext only) = encrypted blob; key never leaves device. Sync trigger: push at session end, pull on app open (feels "always on" without per-strum write load). OVERRIDES AMENDMENT-11 on-device-only wording. Open items from Grill #1 ALL CLOSED (recovery key → decision #4; Q2 mastery shape → decision #5). (2026-08-23, ratified)
